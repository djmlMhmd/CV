# 📝 Éditeur PDF - Guide d'utilisation

Un éditeur PDF moderne et intuitif qui vous permet de modifier directement le texte de vos documents PDF.

## 🚀 Accès rapide

Ouvrez `pdf-editor.html` dans votre navigateur ou cliquez sur le bouton "PDF Editor" sur la page principale.

## ✨ Fonctionnalités

### 📁 Chargement de PDF
- Cliquez sur "Charger un PDF" pour sélectionner votre fichier
- Support des fichiers PDF de toutes tailles
- Affichage instantané avec rendu haute qualité

### ✏️ Édition de texte
1. **Cliquez sur n'importe quel texte** du PDF pour l'éditer
2. Une fenêtre modale s'ouvre avec les options d'édition
3. Modifiez le contenu, la taille ou la couleur
4. Cliquez sur "Appliquer" pour valider

### 🎨 Personnalisation
- **Taille du texte** : Ajustez de 8pt à 72pt
- **Couleur** : Choisissez n'importe quelle couleur avec le sélecteur
- Prévisualisation en temps réel

### 📄 Navigation
- **Pagination** : Naviguez entre les pages avec les boutons ◀ ▶
- **Compteur** : Voir la page actuelle et le nombre total de pages
- **Touches clavier** : (à venir)

### 🔍 Zoom
- **Zoom In/Out** : Ajustez le niveau de zoom de 50% à 300%
- **Boutons** : Utilisez les boutons 🔍+ et 🔍-
- Zoom centré sur le document

### 💾 Sauvegarde
- **Bouton Sauvegarder** : Exportez votre PDF modifié
- Téléchargement automatique du fichier
- Format : `document_modifie.pdf`
- Conservation de la qualité originale

### 🔄 Réinitialisation
- **Annuler toutes les modifications** en un clic
- Retour au PDF original
- Confirmation avant réinitialisation

## 🎯 Cas d'usage

### Pour les documents administratifs
- Corriger des erreurs de frappe
- Mettre à jour des informations personnelles
- Modifier des dates ou des montants

### Pour les CV
- Actualiser vos expériences
- Corriger des informations de contact
- Personnaliser le contenu

### Pour les formulaires
- Remplir des champs de texte
- Modifier des réponses
- Personnaliser des documents

## 💡 Astuces

1. **Survolez le texte** : Les zones modifiables s'affichent en surbrillance
2. **Modifications multiples** : Éditez plusieurs textes avant de sauvegarder
3. **Prévisualisez** : Vérifiez vos modifications avant de sauvegarder
4. **Zoom** : Zoomez pour une édition précise des petits textes

## 🔧 Technologies

- **PDF.js** : Rendu et extraction de texte
- **pdf-lib** : Modification et export de PDF
- **Canvas API** : Affichage haute qualité
- **CSS moderne** : Interface responsive et animations

## ⚠️ Limitations actuelles

- L'édition ne supporte que le texte (pas les images)
- La position du texte est préservée mais peut varier légèrement
- Les polices peuvent être substituées si non disponibles
- Testé sur Chrome, Firefox et Safari
